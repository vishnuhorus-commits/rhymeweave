THREE STEPS

1. Paste writing, ADD FILES / ZIP, or ADD FOLDER.
2. CHOOSE YOUR A–Z FOLDER. In the Windows picker, select D:\HORUS_AZ_FILE_FOUNDATION, or its actual container of letter folders.
3. SEPARATE & FILE. New copies go into A–Z and PHONETIC_FAMILIES. Touch a glyph chamber to read the actual local letter folder.

Start with one small file. PREVIEW — NO SAVING shows its routes, duplicate count, and input notes without writing or downloading anything. Filing rechecks the current input and destination, rather than applying an old preview.

Your folder choice is remembered in this browser when supported. Reopening the page does not write files or grant new permission. If permission needs renewal, click RECONNECT SAVED FOLDER. CHANGE A-Z FOLDER chooses another destination. BROWSE SAVED FOLDERS opens A–Z, sound-family folders, and past run indexes even after reopening the page. Only the folder handle is remembered—not writing or passwords.

The browser cannot connect to D: simply because its path is printed on a page. Folder permission is granted by your Windows browser, not by the Manus side panel. Your Windows files have not been migrated during development; testing used only sample fixtures.

YOUR EXISTING LAYOUT

Plain A/B/C folders, numbered 01_A through 26_Z folders, and nested A-Z/A, A_Z/A, or AZ/A layouts are recognized. When several layouts exist, the one with the most existing letter directories is chosen. Preview lets you check the routes. Original folders/files are not renamed or replaced; new files have unique batch names. H: is not automatically changed.

If you prefer no folder permission, DOWNLOAD FOLDER ZIP. Extract the entire ZIP together; its per-run INDEX.html has real relative file/directory links. ZIPs include original inputs and source references, so keep them private unless you intentionally share them. The portable ZIP uses standard A-Z folders.

FROM YOUR OTHER TOOLS

Temple Sorter v002: add its A–Z ZIP. The funnel selects original-wording letter buckets, not clean-uppercase duplicates, run logs, README files, or secondary indexes. The complete original ZIP remains preserved. Temple checkpoints are backups: restore in Temple first, then export its ZIP.

Constant Consonants SAFE PILOT: use Export approved text there, then add that TXT to the funnel. Dictionary backup JSON is not writing input. The pilot's browser storage, original wording, review/approval decisions, and backups are not changed or automatically promoted.

SAFETY AND FAMILY RULES

The existing Command Desk and browser archive remain unchanged. Nonblank writing lines keep their original case and punctuation. Duplicate occurrences are recorded in review/provenance; original inputs remain intact. A balance check must pass before filing.

Sound-family folders reuse the Command Center's starting-sound/consonant-skeleton approximation. A line can belong to several families. These are suggestions, not a pronunciation dictionary. Unknown/non-Latin writing stays in the underscore A–Z bucket and Review rather than being discarded. A–Z uses the first alphabetic letter of the writing, not its filename.

TXT/Markdown, CSV/JSON text, inert HTML visible-text extraction, DOCX paragraphs, and ZIP intake are supported. HTML is not run or allowed to load embedded resources during extraction. For an old HTML tool, export its actual writing first; static page labels are not its browser-stored archive. PDF/scans, RTF, and unsupported formats are reported, not guessed. Nested ZIPs are not recursively expanded.

Use manageable batches: 32 MiB per input file, 96 MiB queued input, 128 MiB expanded data, 200,000 line records, and 220 MiB generated output. Text outputs split into chunks of up to 5,000 lines. Oversized batches stop rather than silently truncate. Folder browsing shows up to 300 folder/file entries and limited text previews; saved files remain complete.

This is a button-operated local funnel, not an unattended watcher or cloud uploader. Supabase was not connected, so no database tables or writing were changed/uploaded. No cloud backup is claimed. Writing is filed only after you connect the destination and choose SEPARATE & FILE.
